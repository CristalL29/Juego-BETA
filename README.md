# Stellious: Learn English by playing

Una aventura visual 2D para aprender inglés básico mientras ayudas a los habitantes de Stellious a recuperar sus palabras.

## Requisitos

- Node.js y npm

## Iniciar el juego

```bash
npm install
npm run dev
```

Abre la dirección local que muestra Vite en el navegador.

## Progreso

Completa los diez desafíos en orden para desbloquear la aldea. El nombre, el aspecto y los niveles terminados se guardan en este navegador. La música ambiental se puede activar o silenciar desde la barra superior.
